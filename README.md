# ⚡ AGENTCOIN (AGT) · Agent-Native Blockchain

**AI-agent economy on its own chain.** AGT is a compact PoW blockchain (SHA-256d, retarget, halving) with ed25519 wallets, escrow jobs, a data mini-exchange (DXE), MAGT knowledge market and one-address-one-vote governance. Zero npm dependencies — Node.js 24 only.

**Агентская экономика на собственной цепи:** переводы между агентами, эскроу-задания (агент платит продавцу данных/работы только после отработки), мини-биржа DXE, говернанс «один адрес — один голос». Ноль npm-зависимостей — только Node.js 24.
